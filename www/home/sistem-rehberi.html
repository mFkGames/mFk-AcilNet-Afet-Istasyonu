1. Wi-Fi Hotspot ve Erişim Noktası Sorun Giderme

Wi-Fi yayını kesildiğinde veya telefonlar IP alamadığında çalıştırılacak komutlar:

# Wi-Fi kart durumunu kontrol et
sudo rfkill unblock all
ip link show wlan0

# Hostapd ve DHCP servislerini yeniden başlat
sudo systemctl restart hostapd
sudo systemctl restart dnsmasq

# Bağlı kullanıcıları listele
sudo arp-scan --interface=br0 --localnet

2. Disk Doluluğu ve Acil Alan Açma

# Disk doluluk oranını kontrol et
df -h /library /

# Log dosyalarını temizle ve acil yer aç
sudo journalctl --vacuum-size=50M
sudo rm -rf /tmp/* /var/tmp/*
sudo apt clean

3. Raspberry Pi Donanım ve Voltaj Kontrolü

# Sıcaklık ve Voltaj kontrolü
vcgencmd measure_temp
vcgencmd get_throttled

# Açıklama:
# 0x0   -> Normal voltaj ve sıcaklık
# 0x50000 -> Geçmişte düşük voltaj veya ısınma yaşanmış
# 0x50005 -> ANLIK DÜŞÜK VOLTAJ! Adaptörü veya kabloyu değiştirin.
